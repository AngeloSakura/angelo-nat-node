# 测试与审查报告

2026-11-09 汇总上传。测试日期和对象以每份报告为准，本次只归档文档与脱敏证据，没有发布新的程序版本。

**64 MiB 加探针不能承诺 10 人高并发稳定：两轮实机测试都出现第二轮 80 并发整轮失败。128 MB 的已测负载表现较好，但其中一次持续负载出现短暂健康接口异常，不能据此承诺所有功能零故障。**

每个目录的 `SHA256SUMS.txt` 可核验公开报告、结果和附件。ZIP 内另有文件清单与校验值。结果 JSON 保留失败轮次；先读报告中对无效发生器轮次、陈旧统计和补测的解释，再判断通过范围。

第三份报告在**隔离主站**核账，生产主站仅只读检查。它不代表已对生产全部真实用户逐笔对账。前两份报告的测试账号由节点 API 创建，其结果不能单独证明主站倍率入账正确。生产原有一个离线节点的状态在本轮前后都存在，没有在本轮修复。
